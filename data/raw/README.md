# data/raw

Intentionally empty.

This project uses **no confidential or company data**. If public data were used
(e.g. published regulator statistics or reliability handbook summaries) the raw
files would be placed here with their source and licence recorded alongside, and
processed by a script in `scripts/`. All values currently in the model are
documented assumptions (see `docs/data_dictionary.md`), and all records in
`data/synthetic/` are generated with a fixed seed by `scripts/generate_synthetic_data.py`.
